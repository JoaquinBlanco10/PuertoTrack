PuertoTrack

Sistema de Gestión y Trazabilidad de Contenedores Portuarios

Proyecto desarrollado para la asignatura Principios de Arquitectura de Software, correspondiente a la Evaluación Sumativa 2 de Ingeniería Civil Informática, Universidad Autónoma de Chile.

1. Descripción del proyecto

PuertoTrack es un prototipo académico orientado a la gestión y trazabilidad de contenedores dentro de un recinto portuario.

El sistema permite registrar contenedores, administrar sus ubicaciones y controlar movimientos de entrada, traslado y salida. Además, mantiene un historial de las operaciones realizadas y registros de auditoría para identificar los cambios efectuados por los usuarios.

También se implementaron dos microservicios independientes, RFID y Accesos, que permiten simular la identificación de contenedores y evaluar preliminarmente su habilitación mediante comunicación MQTT.

El proyecto representa una parte funcional de una propuesta de sistema portuario más amplia. No corresponde a una solución industrial lista para producción.
